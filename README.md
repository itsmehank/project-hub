# Project Hub

`~/git/personal` 아래 개인 프로젝트를 한 화면에서 보는 로컬 대시보드.
프로젝트 설명(Claude 요약), 마지막 개발 시점, git 상태, GitHub 이슈·PR·CI, 로컬 실행 여부를 보여주고,
실행 중이면 바로 접속하고, 아니면 실행·중지할 수 있다.

## 화면

- `#/` 첫 화면: 지금 실행 중 → 현황(지표·26주 커밋·스택 분포, 보관 제외) → 주의할 것(push 안 한 커밋, 30일 넘게 열린 PR, 잊혀진 변경)과 백업 없음 → AI 제안(Opus 분석: 서비스 후보, 정리 제안, 신규 아이디어, 개발 성향). 제목 "Project Hub"를 누르면 돌아온다.
  - AI 제안마다 **채택·보류·거절**을 남길 수 있고, 맨 위 "내 결정" 칸에 모인다. 채택한 서비스 후보는 공개 체크리스트로 진행을 추적한다.
  - 분석 이후 태그·결정이 바뀌면 "다시 분석" 안내가 뜬다(자동으로 다시 분석하지는 않는다).
- `#/p/<이름>` 프로젝트 상세: 한 줄 설명 → 내 태그·메모·바로가기 링크 → 이 프로젝트는 → 현재 상태 → AI 제안(채택한 후보면 공개 체크리스트) → 개발 정보.
- `#/p/<이름>/issues` 이슈·PR 전체: 열린/닫힌 이슈와 열린 PR, 검색, 라벨 필터, 정렬, 본문 미리보기.
- `#/week`, `#/week/-1`, `#/week/-2` 주간 리뷰: 월요일 0시 기준 한 주의 커밋(직전 주 대비), 손댄 프로젝트, 닫힌 이슈, 머지된 PR, 이어갈 후보, 현재 미커밋. 상단 "주간 리뷰" 링크로 연다.

### 태그

목록 위 태그 선택으로 거른다(태그 → 필터 칩 → 검색어 순). 집중·유지·공개 준비·실험·보관·미분류.
"보관"은 기본 목록·지표·주의 신호에서 빠지고, 태그 선택을 "보관"으로 바꿀 때만 보인다.

## 실행

```bash
pnpm install
pnpm dev        # API 127.0.0.1:4310 + 웹 http://127.0.0.1:5199
```

처음 실행하면 DB가 비어 있어 자동으로 전체 수집을 시작한다(Claude 요약 때문에 수 분 걸린다).
새로고침으로 요약이 바뀌면 인사이트를 Opus로 다시 분석한다(1~2분). 첫 화면의 "인사이트 다시 분석"으로 직접 실행할 수도 있다.
이후에는 오른쪽 위 **새로고침** 버튼으로 수동 갱신한다. **Shift+클릭**하면 Claude 요약까지 전부 다시 만든다.

## 필요 조건

- Node 22.13+ (내장 `node:sqlite` 사용), pnpm
- `gh`가 github.com에 로그인되어 있을 것 (`gh auth login --hostname github.com`)
- `claude` CLI (요약 생성)
- `lsof`, `ps` (macOS 기본)

## 환경 변수

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `HUB_ROOT` | `~/git/personal` | 스캔할 루트 |
| `HUB_SUMMARY_MODEL` | `sonnet` | 프로젝트 요약에 쓸 Claude 모델 |
| `HUB_INSIGHTS_MODEL` | `opus` | 첫 화면 인사이트 분석에 쓸 Claude 모델 |
| `HUB_PORT` | `4310` | API 포트 (바꾸면 `web/vite.config.ts`의 proxy도 함께 수정) |
| `HUB_EDITOR` | 자동 | "편집기에서 열기"에 쓸 앱 이름. 없으면 Python은 PyCharm, 그 외는 IntelliJ IDEA, 둘 다 없으면 Finder |

## 데이터

- `data/hub.db` — 수집 결과, 요약 캐시, 실행 명령, 실행 기록, 내 태그·메모·링크, AI 제안 결정 (gitignore)
- 새로고침 때 주간 리뷰용으로 30일치 커밋(최대 500개)·머지된 PR·닫힌 이슈를 모은다. 상한에 닿은 저장소는 "일부만 집계"로 표시된다.
- `data/logs/<project>.log` — 허브가 실행한 프로세스의 출력. 실행할 때마다 덮어쓴다.

## 실행 관리 동작

- 실행 중 감지는 프로세스의 작업 디렉토리(cwd)가 프로젝트 폴더 안에 있는지로 판단한다. 셸·에디터·`claude` 세션은 제외한다.
- 실행 명령은 직접 등록한 명령 → Claude가 추정한 명령 순으로 쓴다. 추정 명령은 처음 실행할 때 확인 모달에서 승인해야 한다.
- `astro dev`처럼 서버를 따로 띄우고 자신은 끝나는 명령도 새로 생긴 서버 프로세스를 따라가 실행 중으로 표시한다.
- 허브가 띄운 프로세스는 바로 중지하고, 터미널에서 직접 띄운 프로세스는 확인을 거쳐 중지한다.
